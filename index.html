What is it

Every AI coding tool — Cursor, Claude Code, Windsurf — generates Python. Running that code safely is an unsolved problem.

Jhansi.io provides a runtime layer: hard-isolated execution per run, secrets injected safely so AI can use them but can't steal them, and a full audit log for compliance.

Open source for self-hosting. SaaS for teams who don't want the infra.
